# MedConform

Aplicação simples com backend em Flask e frontend estático em HTML, CSS e JavaScript.

## Estrutura

- backend: API Flask com endpoints para gerenciamento de documentos
- frontend: página estática que consome a API Flask diretamente

## Como executar

### Backend

```bash
cd backend
python app.py
```

A API ficará disponível em http://127.0.0.1:5000.

### Frontend

Abra o arquivo frontend/index.html diretamente no navegador ou use qualquer servidor estático simples.
A página consome a API Flask via JavaScript.
